1. Loan Payments¶

Numpy Financial has some useful functions for calculating interest payments. Let's assume you need a $500,000 mortgage for a house and the annual mortgage rate for a 30-year loan is 3%.

In [2]:
mortgage_amount=500_000
months_per_year = 12
mortgage_term = 30 #years
interest_rate=0.03/months_per_year
n_periods = mortgage_term * months_per_year

1.1 Payment function¶

How much are the payments? We can use the numpy financial's pmt function.

In [3]:
import numpy_financial as npf
monthly_payment = npf.pmt(interest_rate, n_periods, mortgage_amount)
print(f"Mortgage payment: ${-monthly_payment:,.2f}")

Mortgage payment: $2,108.02

1.2 Interest and principal payments functions¶

How much is being charged as interest? Let's decomposes the payments into interest and principal using the ipmt and ppmt functions.

In [4]:
interest = []
principal = []
periods = range (1, n_periods + 1) 

for i in periods:
    interest.append(npf.ipmt(rate=interest_rate, per=i, nper=n_periods, pv=mortgage_amount))
    principal.append(npf.ppmt(rate=interest_rate, per=i, nper=n_periods, pv=mortgage_amount))

print(f"The first payment is: ${-interest[0]:,.2f} interest and ${-principal[0]:,.2f} principal")

The first payment is: $1,250.00 interest and $858.02 principal

2.3 Using Wharton Research Data Services¶

WRDS-Py is a library for extracting data from WRDS data sources and getting it into Pandas. The library allows users to access data from WRDS and extract data using SQL statements. The data that is returned is read into a Pandas dataframe.

If you wish to make an account, you can head to https://wrds-www.wharton.upenn.edu/ and follow these instructions:

  1. Use Subscriber "University of Pennsylvania" and User type "Masters/Undergrad"
  2. Wait a few days for approval (you'll receive an email)
  3. Once approved, try to establish a database connection
  4. If authentication fails, submit a request and it'll be routed to the appropriate support team

Getting started with accessing WRDS using python: # https://wrds-www.wharton.upenn.edu/pages/support/programming-wrds/programming-python/python-from-your-computer/

3. Retirement Savings¶

Let's say that we start savings at age 30 and want to know how much we'll have by retirement, and whether that will be enough to sustain a comfortable lifetime in retirement.

In [13]:
income = 100_000
save_pt = 0.15 # save 15% of income
current_age = 30
retire_age = 60
retire_consumption = 80_000 #post-retirement spending
work_years = retire_age - current_age

Using our S&P data, let's calulate the investment returns we could expect:

In [14]:
years = 2020 - 1927
sandp_end = sandp.loc['2020-12-30']['Adj Close'] 
sandp_start = sandp.loc['1927-12-30']['Adj Close']
investment_returns = (1+(sandp_end- sandp_start)/sandp_start)**(1/years)-1
print(f"S&P returns: {investment_returns*100:.2f}%")

S&P returns: 5.93%

3.1 Future value function¶

How much will we have at retirement?

In [15]:
savings_at_retirement_start = npf.fv(rate=investment_returns, nper=work_years, pmt=-income*save_pt, pv=0) # payment is negative
print(f"Savings by the age of {retire_age}: ${savings_at_retirement_start:,.2f}")

Savings by the age of 60: $1,170,386.83

3.2 Present value function¶

Will that be enough to last for retirement?

In [16]:
age = 95
retirement_spending = npf.pv(rate=investment_returns, nper=age-retire_age, pmt=-retire_consumption)
savings_at_retirement_end = savings_at_retirement_start - retirement_spending
print(f"After spending ${retirement_spending:,.2f}, you will have ${savings_at_retirement_end:,.2f} left by the age of {age} ")

After spending $1,170,099.95, you will have $286.89 left by the age of 95
